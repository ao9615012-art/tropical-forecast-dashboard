# لوحة التنبؤ المداري

هذه نسخة الويب من الملف المرفق **لوحة_التنبؤ_المداري.html**، منشورة كصفحة ثابتة عبر GitHub Pages.

## التحديث

الملف الأصلي صفحة ثابتة؛ الخرائط والصور مضمّنة داخله بصيغة Base64، ولا يحتوي على API أو سكربت يستخرج بيانات جديدة من NOAA أو GFS أو CFSv2. لذلك فإن النشر الحالي يحافظ على محتوى الملف كما هو، مع إعادة تحميل الصفحة تلقائيًا كل 6 ساعات.

للحصول على **بيانات جديدة فعلية** نحتاج سكربت التوليد أو مصدر البيانات/API الذي أُنشئت منه الخرائط. عند توفيره يمكن ربطه بـ GitHub Actions ليُشغّل دوريًا ويعيد بناء `index.html`.

## التشغيل

افتح رابط GitHub Pages للمستودع، أو افتح `index.html` محليًا في أي متصفح حديث.
