# لوحة التنبؤ المداري

هذه نسخة الويب من الملف المرفق **لوحة_التنبؤ_المداري.html**، منشورة كصفحة ثابتة عبر GitHub Pages.

أضيفت إلى الصفحة لوحة حية مرتبطة بواجهتي [Open-Meteo Weather Forecast API](https://open-meteo.com/en/docs) و[Open-Meteo Marine API](https://open-meteo.com/en/docs/marine-weather-api)، وتعرض الحرارة والضغط والرياح وارتفاع الموج وحرارة سطح البحر وتوقعات الساعات القادمة لمنطقة بحر العرب وخليج عدن. لا تحتاج الواجهتان إلى مفتاح API للاستخدام غير التجاري، وتُعاد المزامنة داخل الصفحة كل 30 دقيقة.

يوجد الآن API محلي بصيغة JSON في `api/live.json`. يقوم سير عمل GitHub Actions في `/.github/workflows/update-live-data.yml` بجلب أحدث البيانات كل 30 دقيقة، والتحقق من الاستجابة، ثم حفظها تلقائيًا في المستودع. تقرأ الصفحة هذا الملف أولًا، وتستخدم الاتصال المباشر بمصادر Open-Meteo كخطة احتياطية إذا لم يتوفر الملف المحلي.

## التحديث

الخرائط الأصلية والصور ما زالت مضمّنة داخل الملف بصيغة Base64، لكن معلومات الطقس والبحر الجديدة تظهر الآن في قسم مستقل حي. بيانات Open-Meteo ليست بديلًا مطابقًا لمؤشر EURO-GPI الأصلي؛ فهي طبقة بيانات تشغيلية للطقس والبحر، بينما تبقى خرائط المؤشر الأصلية كما وردت في الملف المرفق.

للحصول على **بيانات جديدة فعلية** نحتاج سكربت التوليد أو مصدر البيانات/API الذي أُنشئت منه الخرائط. عند توفيره يمكن ربطه بـ GitHub Actions ليُشغّل دوريًا ويعيد بناء `index.html`.

## التشغيل

افتح رابط GitHub Pages للمستودع، أو افتح `index.html` محليًا في أي متصفح حديث.
